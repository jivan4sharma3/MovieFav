# 🎬 MovieFav

MovieFav is a simple and clean movie listing application where users can browse movies, view details, and manage favourites.  
This repository contains both **frontend** and **backend** folders for a complete full-stack structure.

---

## 📁 Project Structure

MovieFav/

├── frontend/ # React UI (pages, components, assets)

└── backend/ # Node/Express server & API logic

---

## 🚀 Features

- Browse movie posters & details  
- Add movies to favourites  
- Responsive movie cards  
- Clean UI with simple animations  
- Frontend + Backend integrated structure  

---

## 🛠️ Tech Stack

### **Frontend**
- React.js  
- CSS  
- JavaScript  

### **Backend**
- Node.js  
- Express.js
